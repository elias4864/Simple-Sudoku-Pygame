# A Simple Game Based on Python – Sudoku

## Description
This project is a simple Sudoku game developed using Python. The game provides a 9x9 Sudoku grid where players can enter numbers and try to complete the puzzle.

## Features
- Simple and easy-to-use interface
- 9x9 Sudoku grid
- Pre-filled numbers
- Input fields for missing numbers
- Report of Succes when Finished
- Button to check if all fields are completed

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python on your computer.
2. Copy the Python code into a file called `sudoku.py`.
3. Open a terminal of your choice(CMD or PS)
4. Run the following command:
5. Change Directory into Root Directory /Sudoku
6.Start the Game
python main.py


## How to Play
1. Start the game.
2. Look at the Sudoku grid.
3. Enter numbers from 1 to 9 into the empty fields in the Grid
4. Click the "Check" when you are finished with filling the Numbers.

## Project Goal
The goal of this project is to create a simple game using Python and learn basic programming concepts such as loops, functions, lists and graphical user interfaces.
